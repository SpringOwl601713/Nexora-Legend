# Nexora Légend

Nexora Légend est une application desktop destinée aux créateurs TikTok Live. Le projet vise à proposer un gestionnaire de live moderne avec événements temps réel, triggers, overlays, TTS, mini-jeux et automatisations.

## Objectifs de la première version

- Application desktop Electron + TypeScript
- Interface React
- Connexion à un live TikTok
- Réception des événements : commentaires, likes, follows, shares et gifts
- Moteur de triggers configurable
- Journal temps réel des événements
- Base pour overlays OBS et TTS

## Développement

```bash
npm install
npm run dev
```

## Build Windows

```bash
npm run build
npm run dist
```

> Le projet est développé indépendamment. Il ne reprend pas le code propriétaire de TikFinity, Tik360 ou Streamshot.
